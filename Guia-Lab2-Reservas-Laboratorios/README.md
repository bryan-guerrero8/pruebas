## Descripción

El sistema permite consultar la disponibilidad de laboratorios universitarios, solicitar reservas para sesiones académicas y administrar las solicitudes realizadas por docentes y estudiantes autorizados.

## Alcance

El sistema contempla el registro de solicitudes, consulta de disponibilidad, aprobación o rechazo de reservas, cancelación y consulta del historial. No incluye control físico de acceso ni integración con sistemas externos de matrícula en esta versión.
